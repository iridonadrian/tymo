Tymo
Extension settings
Connection
The desktop app and a local install use http://127.0.0.1:3210.
Create one in Tymo → Settings → Browser extension. It stays in this browser only.
Tymo asks permission for this one address only.
Behaviour
Shortcuts
Open the Tymo popupAlt Shift S Save the current tab instantlyAlt Shift D Save the window's tabs as a sessionAlt Shift E Save from the popup⌘/Ctrl ↵
Change them at chrome://extensions/shortcuts, or in Firefox at about:addons → ⚙ → Manage Extension Shortcuts.
Right-click menu
Save a page, link, image, selection (as a quote) or screenshot · add a page or link to Bookmarks · search Tymo for selected text. Right-click the toolbar icon to open your Inbox or Bookmarks.
