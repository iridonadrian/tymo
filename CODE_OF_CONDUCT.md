# Code of Conduct

We adopt the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, welcome newcomers, and
focus critique on ideas and code, never people. Harassment, discrimination, personal
attacks and publishing others' private information are not tolerated.

Report unacceptable behavior privately to the maintainers via GitHub (open a private
security advisory or contact a maintainer directly). Reports are handled confidentially.
Maintainers may remove, edit or reject contributions and temporarily or permanently ban
participants who violate this code.
